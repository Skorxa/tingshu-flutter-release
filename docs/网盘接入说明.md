## 4. 抓包方法

### 4.1 环境

- 手机（Android）安装 **ProxyPin**，与开发机同一局域网；ProxyPin 开启抓包并让目标 App 走代理。
- 本会话有 MCP 抓包服务 `proxypin_mobile`，**当前状态为 `disconnected`**：`list_mcp_resources` / `list_mcp_resource_templates` 均返回 `mcp-client(proxypin_mobile): server is disconnected`。需先在 dsh 里把它连上，之后才能用它列举设备/会话/请求详情并导出。
  - 连接后应确认的具体工具名与参数 schema：**待核对**（当前无法枚举，不要凭猜测调用）。
- 兜底路径：手机端 ProxyPin 直接「导出 JSON」，产物按 §4.4 的格式落到 `docs/`。

### 4.2 要抓的最小请求集合

| # | 请求 | 目的 | 要记下的字段 |
|---|---|---|---|
| 1 | **登录后的一次列目录请求**（115：`GET /files`；阿里云盘：`POST /adrive/v3/file/list`） | 核对路径、query/body 参数名、分页字段、响应条目字段名 | method、url（含 query）、request_headers 的 UA/Referer、request_body、status_code、response_body 结构 |
| 2 | **一次取直链请求**（115：`GET /files/download`；阿里云盘：`POST …/get_download_url`） | 核对直链是 302 `Location` 还是 JSON 字段 | status_code（是否 302）、`Location` 响应头（值只记结构）、响应体里 url/expiration 字段名 |
| 3 | **实际播放请求**（点开某一集触发，CDN 上的 GET，带 `Range`） | 核对 CDN 真正要求的头 | `User-Agent`、`Referer`、`Cookie`/`Authorization`、`Range`、是否 206 |
| 4 | 阿里云盘额外：**登录态与刷新** | 核对 `localStorage.token` 形态与 `/token/refresh` 是否要 `client_secret` | localStorage 里 `token` 的值结构（脱敏后只留键名）、refresh 请求 body 字段名、响应 `expires_in` 字段名 |

操作步骤：App → 设置 → 音源 → 进入目标网盘页 → 登录（内置浏览器或粘贴）→ 浏览一次目录 → 打开一本 → 播放第 1 集 → 切到第 2 集。即可覆盖上表 1–3 全部请求。

### 4.3 要脱敏的字段（**不要贴进文档、不要提交**）

| 字段 | 处理 |
|---|---|
| `Cookie` 请求头（整条，含 `UID`/`CID`/`SEID` 等） | 替换为 `<COOKIE>` |
| `Authorization` / `access_token` / `refresh_token` / `Bearer …` | 替换为 `<TOKEN>` |
| `client_secret` / `client_id` | 替换为 `<CLIENT_SECRET>` / `<CLIENT_ID>`，或整条删除 |
| `Location` 与阿里云盘直链里的 `sign` / `Expires` / `auth_key` 等签名参数 | 替换为 `<SIGN>` |
| `drive_id` / `default_drive_id` / `user_id` / `uid` | 替换为 `<DRIVE_ID>` / `<UID>` |
| 设备指纹（`device_id`、`x-device-id`、`x-signature`） | 替换为 `<DEVICE>` |
| 账号、手机号、邮箱 | 替换为 `<ACCOUNT>` |

> ⚠️ 反面示例：仓库现有抓包产物 `docs/速-2026-07-25.json` 的第 1 条记录里**明文带了邮箱、密码与 JWT**（`request_body` 与 `response_body`）。新抓包文件不要照抄这个习惯——落盘前先按上表替换。

### 4.4 抓包产物格式（照 `docs/速-2026-07-25.json`）

顶层是数组，每条记录字段：

```
id, session_id, sequence, timestamp, method, url,
request_headers(JSON 字符串), request_body,
status_code, response_headers, response_body,
content_type, initiator, duration_ms, is_streaming, is_websocket, source
```

新抓包建议命名 `docs/<源名>-<YYYY-MM-DD>.json`（例：`docs/pan115-2026-10-12.json`、`docs/aliyun-2026-10-12.json`），并与本文 §3 的核对表逐条对照后回填代码。

## 5. 安全与合规提醒

### 5.1 凭据只能进 `SecureStore`

- 所有 Cookie / token / 密码 / 邀请码统一走 `SecureStore`，键名以 **`sec.`** 前缀；Android 后端是 `EncryptedSharedPreferences`（Keystore 主密钥加密），见 `lib/data/secure_store.dart:16-35`。
- 旧版本明文存在 SharedPreferences 的键由 `readMigrated(prefsKey, secureKey)` 一次性搬迁，迁移成功才删旧键（`secure_store.dart:105-142`）。

现有 `sec.` 键清单：

| 键名 | 归属 | 位置 |
|---|---|---|
| `sec.webdav_accounts` | WebDAV 书库 | `webdav_service.dart:107` |
| `sec.sync_password` / `sec.sync_webdav_config` | WebDAV 多设备同步 | `webdav_sync_service.dart:282-283` |
| `sec.alist_accounts` | AList | `alist_service.dart:97` |
| `sec.baidu_pan_config` | 百度网盘 | `baidu_pan_service.dart:93` |
| `sec.quark_pan_config` | 夸克网盘 | `quark_pan_service.dart:92` |
| `sec.pan115_config` | 115 网盘 | `pan115_service.dart:112` |
| `sec.aliyun_pan_config` | 阿里云盘（含 access/refresh token、client_secret） | `aliyun_pan_service.dart:125` |
| `sec.cloud_auth_access_token` / `_refresh_token` / `_license` / `_invite_code` | 设备授权 | `cloud_auth_service.dart:100-103` |

### 5.2 日志只记长度与字段名

- 115 保存 Cookie 时只记长度 + **键名列表**：`pan115_service.dart:179-183`，`cookieSummary()` 只取 `=` 前的键名、最多 12 个（:257-265）；页面也只展示该摘要（`pan115_screen.dart:513-518`）。
- 阿里云盘只记 token 长度与段数：`tokenSummary()`（`aliyun_pan_service.dart:381-386`），`init`/`saveLogin`/刷新日志都用它（:212-222,261-271,969-971）；直链日志只记 `scheme://host/path?<签名参数已省略>`（`_urlSummary` :506-513，用于 :873）。
- `client_id`/`client_secret` 只记「已填/未填」或长度，绝不记值：`aliyun_pan_service.dart:220-221,288-289,969`。
- 缓存下载失败时对请求头脱敏：`cookie`、`authorization`、含 `token`/`secret`/`api-key`/`apikey` 的键一律置 `***`（`cache_service.dart:1263-1277`）。
- 诊断报告导出前对 URL 里的 `token|key|sign|sig|auth|access_token|refresh_token|password|pwd` 与 `Authorization: Basic …` 做尽力脱敏（`log_service.dart:142-161`），并在报告头提示「导出前请再人工检查」（:127）。

### 5.3 不要写进代码或文档

`client_secret`、Cookie、access/refresh token、pickcode（半敏感，等同文件句柄）、CDN 签名直链、`drive_id`、设备指纹。**一律不要出现在源码常量、注释、日志或本文档中。**

阿里云盘已按此约定实现：`client_id`/`client_secret` **不硬编码**，只接受用户自填（`aliyun_pan_service.dart:103-104,277-292`）；用户没填且 access_token 过期时直接提示重新登录，而不是内置应用凭据去刷新（:944-951）。
